# 💸 Money Fintrack

### Full-Stack Finance Management Application

Money Fintrack is a full-stack web application that helps users manage their accounts, check balances, transfer money, and track transaction history through a clean and responsive interface.

## ✨ Features

- 🔐 User Registration & Login
- 💰 Account Balance Management
- 💸 Money Transfer
- 📊 Transaction History
- 👤 Profile Management
- 🗑️ Account Management
- 📱 Responsive User Interface

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Python, Flask, REST APIs
- **Database:** MongoDB
- **Caching:** Redis
- **Tools:** Git, GitHub

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Money-Fintrack.git
cd Money-Fintrack
```

### 2. Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Run the Backend

Activate your Python virtual environment, install dependencies, configure the required environment variables, and start the Flask application using your backend entry point.

Ensure MongoDB and Redis are configured and running as required by your application.

## 🔒 Environment Variables

Configure your required database URLs, secret keys, and other credentials in local `.env` files. **Never upload secrets or credentials to GitHub.**
